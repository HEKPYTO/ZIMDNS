# ZIMDNS RFC standards matrix

**Version:** 2026-10-05 (RFC-parity ledger revision), RFC-first minimal CLI design
**Product profile:** one Zig binary, local-first authoritative DNS, controlled by a CLI; no web UI or admin socket
**Status:** normative release-profile evidence map

This matrix is the source of truth for the declared first-release profile. It separates the current repository baseline from the release target and from work that is deliberately outside the profile. A behavior is user-facing `supported` only after the linked RFC requirement, implementation path, and tests pass. A `partial` row names the subset that is actually covered; it is not a claim of full RFC conformance.

Future work is tracked outside this ledger and does not change any current row or make roadmap items user-facing capabilities. The frozen-inventory audit trail is [`docs/reports/2026-08-12-dns-rfc-parity-audit.md`](reports/2026-08-12-dns-rfc-parity-audit.md); it audited the 2026-08-12 revision of this file and is stale for every row changed on 2026-10-05.

The internal quality objective is to make the declared profile more explicit, test-backed, and safe to operate than comparable deployments. That objective is not product copy, a feature-count promise, or a claim that ZIMDNS is generally superior to another DNS server.

## Status vocabulary

| Status | Meaning | Evidence needed |
|---|---|---|
| `supported` | Implemented for the declared profile and safe to advertise. | RFC section, implementation path, and passing unit/golden/integration tests; malformed-input coverage where applicable. |
| `partial` | Only the named subset is implemented. | Tests cover the named subset and the missing behavior is stated. |
| `planned` | Roadmap intent; not a user-facing capability. | A roadmap item and proposed test linkage. |
| `not-applicable` | The RFC does not define behavior for this DNS-only server. | An RFC-scope rationale; no implementation claim. |
| `out of scope` | Deliberately excluded from this profile. | Rationale and, when useful, a pointer to a later research item. |
